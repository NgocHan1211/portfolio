# Tran Ngoc Han Portfolio — Pastel Edition

A bright pastel portfolio covering data analytics, AI/ML research, software engineering, and quality validation. It includes project filters, two copyable email addresses, and an in-page CV viewer.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `ngoc-han-portfolio`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.

GitHub will provide the public URL after deployment finishes.

## Edit content

- Main content and project links: `index.html`
- Visual design and responsive layout: `styles.css`
- Filtering, navigation, and reveal effects: `script.js`

This site uses no build tools or external JavaScript dependencies.
